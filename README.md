# Mobile Application Development – Flutter Semester Report

This project was created as part of the Mobile Application Development course during the semester at university. It contains a practical Flutter application task completed as part of the coursework.

## Project Overview

The main purpose of this project is to learn and apply mobile application development using Flutter. The project focuses on creating a user-friendly mobile app interface and implementing basic features such as:

- Login form design
- Text input fields
- Form validation
- User interface layout
- Navigation and basic app flow
- Flutter widget-based design
