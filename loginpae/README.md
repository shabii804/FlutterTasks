# Mobile Application Development – Flutter Semester Report

This project was created as part of the Mobile Application Development course during the first semester at university. It demonstrates the practical Flutter tasks and learning activities completed throughout the semester.

## Project Overview

The goal of this project is to build a simple mobile application using Flutter that focuses on:

- User interface design
- Form input and validation
- Navigation between screens
- Layout and responsiveness
- Basic app logic and state management

This project serves as a practical example of how Flutter can be used to create a modern mobile application.

## Course Context

Course: Mobile Application Development  
Semester: 1st Semester  
Platform: Flutter / Dart  
Focus: Building mobile applications for Android and iOS using a single codebase

## Flutter Tasks Completed

### 1. App Setup and Environment Configuration
- Installed Flutter SDK and configured the environment
- Created a new Flutter project
- Set up required dependencies and project structure

### 2. UI Design and Layout
- Designed a clean login interface
- Used widgets such as `Container`, `TextField`, `ElevatedButton`, and `Text`
- Applied spacing, colors, and alignment to create a user-friendly design

### 3. Form Input and Validation
- Created username and password fields
- Implemented basic validation for empty input
- Displayed user feedback for incorrect or missing data

### 4. Navigation and Screen Flow
- Built a simple login flow
- Connected the login screen with follow-up screens or actions
- Practiced screen-to-screen transitions in Flutter

### 5. App Styling and User Experience
- Applied consistent themes and colors
- Improved readability and visual structure
- Focused on making the app responsive and attractive

### 6. Testing and Debugging
- Ran the app on a simulator/emulator
- Fixed UI and logic issues
- Reviewed Flutter warnings and errors during development

## How to Run

1. Open the project in VS Code or Android Studio.
2. Make sure Flutter is installed and configured correctly.
3. Run the following command in the project folder:

```bash
flutter pub get
flutter run
```
